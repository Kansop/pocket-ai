Topics

Starting homework

Pick one assignment. Open it and write down the smallest thing you can do next, such as reading the first question. Set a five-minute timer and do just that step. When it rings, decide on the next one.

Remembering what you study

Close your notes and try answering a question from memory. Check your answer, then try the ones you missed again tomorrow. For vocabulary, practice in both directions: word to meaning and meaning to word.

Writing a paragraph

Write your main point in one sentence. Add one detail or quote that supports it, then explain how that detail proves your point. Read the sentences together and check that each one helps explain the same idea.

Planning your day

Start with commitments that already have a time. Pick the one remaining task that matters most and give it a time slot. Leave a little space between tasks in case one takes longer.

Ideas for boredom

Try a ten-minute challenge: photograph three ordinary objects so they look unusual, draw a map of a made-up place, or invent a game using only paper and a coin.

How rain forms

Water evaporates from surfaces and enters the air as vapor. When moist air cools, some vapor condenses into cloud droplets. Droplets can join and grow heavy enough to fall as rain.

Why the sky looks blue

Sunlight contains many colors. Air molecules scatter shorter wavelengths, including blue, more strongly than longer wavelengths like red. That scattered light reaches your eyes from all across the sky.

Changing seasons

Earth's axis is tilted. When your hemisphere tilts toward the Sun, sunlight hits it more directly and the days are longer. Six months later, the other hemisphere tilts toward the Sun.

Moon phases

The Sun lights roughly half of the Moon. As the Moon orbits Earth, we see different amounts of that sunlit half. A crescent means only a narrow slice of the lit side faces us.

Percent of a number

Percent means out of 100. To find a percentage of a number, divide the percentage by 100 and multiply by the number. For example, 15 percent of 80 is 0.15 times 80, which is 12.

Sale prices

For a 20% discount, you pay 80% of the original price. Multiply the original price by 0.80. For example, a $30 item costs $24 before tax.

Finding an average

Add the values together and divide by how many values there are. For 6, 8 and 10, the sum is 24. There are three values, so the average is 8.

Wi-Fi and Ethernet

Wi-Fi sends data by radio between your device and router. Ethernet uses a cable. For gaming, Ethernet often gives more consistent timing because nearby wireless traffic and walls do not affect the cable.

What localhost means

Localhost points back to the device opening the link. If a friend opens your localhost address, their browser looks on their own device. A published website gives both of you a link to the same hosted files.

Storage and memory

Storage keeps files after an app closes. RAM holds the data an app is currently using. When you open a website, the browser uses RAM and may save files in its cache so the page loads faster next time.

Making a sandwich

Try bread, a spread you like, and a filling such as cheese or sliced vegetables. For a packed lunch, dry damp vegetables and keep juicy ingredients separate until you eat.

Finding a lost item

Think of the last moment you remember using it. Walk that route slowly, checking surfaces where you put things down. Then check pockets, bags and the gaps beside furniture one area at a time.

Apologizing to a friend

Name what you did, acknowledge how it affected them and say what you'll do differently. For example: “I interrupted you in front of everyone. That was unfair. Next time I'll let you finish.”

Variables

A variable is a name that refers to a value. Assignment uses one equals sign. You can use the old value when calculating the new one.

score = 10
score = score + 2
print(score)
Reveal the output
12
Printing

Use print() to display values. Put text in quotes. You can pass several values separated by commas.

score = 7
print("Score", score)
Reveal the output
Score 7
User input

input() shows a prompt and returns the user's reply as text. For this example, suppose the user types Ada.

name = input("Name? ")
print("Hi", name)
Reveal the output
Hi Ada
Converting types

Use int() for whole numbers, float() for decimals, and str() for text. The text you convert must have a valid format for that conversion.

points = int("12")
print(points + 3)
Reveal the output
15
Strings

A string holds text. A slice like [1:4] takes characters at positions 1, 2 and 3. Counting starts at zero. upper() returns uppercase text.

word = "python"
print(word[1:4].upper())
Reveal the output
YTH
Lists

A list holds items in order. Index 0 selects the first item. Index -1 selects the last one.

colors = ["red", "blue", "green"]
print(colors[-1])
Reveal the output
green
Appending items

Use append() to add one item to the end of an existing list. It changes the list in place.

items = [2, 4]
items.append(8)
print(items)
Reveal the output
[2, 4, 8]
For loops

A for loop takes one item at a time from a sequence. Indent every line you want to run for each item.

for letter in "AI":
    print(letter)
Reveal the output
A
I
While loops

A while loop checks its condition before each pass. Here, adding one eventually makes the condition false.

n = 1
while n < 3:
    print(n)
    n += 1
Reveal the output
1
2
Range

range(start, stop, step) produces integers up to the stop value, excluding it. With one argument, counting starts at zero.

print(list(range(1, 7, 2)))
Reveal the output
[1, 3, 5]
Conditionals

An if statement checks a condition. elif checks another condition if earlier checks failed. else handles the remaining cases.

score = 8
if score >= 5:
    print("Pass")
else:
    print("Try again")
Reveal the output
Pass
Equality

Use == to test whether two values are equal. Use = to assign a value to a name.

score = 3
print(score == 4)
Reveal the output
False
Functions

Use def to define a function. Parameters receive values when you call it. A return statement sends a result back to the caller.

def double(number):
    return number * 2
print(double(6))
Reveal the output
12
Return values

return ends a function call and passes a value back. print() displays a value. A function that reaches its end without returning a value gives the caller None.

def total(a, b):
    return a + b
answer = total(4, 5)
print(answer)
Reveal the output
9
Dictionaries

A dictionary maps keys to values. Use square brackets for a known key. Use get() with a default for a key that might be missing.

scores = {"red": 4}
print(scores.get("blue", 0))
Reveal the output
0
Indentation

Indentation groups lines into blocks. After a line such as if ready:, indent the lines that belong inside it. Four spaces per level is the usual style.

ready = True
if ready:
    print("Start")
print("Done")
Reveal the output
Start
Done
Index errors

IndexError means the requested position is outside the sequence. A list with three items has nonnegative indices 0, 1 and 2.

nums = [10, 20, 30]
print(nums[len(nums) - 1])
Reveal the output
30
Name errors

NameError means Python could not find a name. Check spelling, capitalization and whether the assignment ran before the name was used.

points = 5
print(points)
Reveal the output
5
Soccer first touch

Let the ball meet the inside of your foot and draw your foot back slightly. Aim your first touch into space where you can take the next step.

Passing in soccer

Plant your standing foot beside the ball, point it toward your target and use the inside of your other foot. Practice against a wall with a small target.

Checking your shoulder

Glance over your shoulder before the pass arrives. Look for a teammate, a defender and a patch of space, then bring your eyes back to the ball.

Packing for practice

Lay out your footwear, shin guards, socks, water bottle and the kit your coach requested. Pack a spare shirt for the trip home.

Comparing game settings

Change one setting at a time. Repeat the same short drill at each setting and record accuracy and comfort before deciding.

Frame rate

FPS counts how many frames a game produces per second. At 60 FPS an evenly spaced frame takes about 16.7 milliseconds. Uneven timing can still look choppy.

Refresh rate

Hertz tells you how many times per second a display can refresh. A 120 Hz display can refresh 120 times each second; the game also has to supply frames.

Game latency

Ping usually measures a network round trip in milliseconds. A 30 ms result means the trip there and back took about 30 milliseconds. Spikes can matter as much as the average.

Bandwidth

Bandwidth is how much data a connection can carry per second. Eight megabits make one megabyte, so 80 Mbps is at most about 10 MB per second before overhead.

Screen resolution

Resolution gives the number of pixels across and down. A 2560 by 1440 image contains 3,686,400 pixels. Screen size determines how spread out they look.

Bookmarks

A bookmark saves the address of a page. Use the browser’s bookmark or favorites command, give it a recognizable name, and open it later from your bookmarks.

ZIP files

A ZIP archive bundles files together and can compress them. Extract it to get ordinary files you can open or edit individually.

File extensions

An extension is the ending after a filename’s final dot. It often identifies the format: .txt for plain text, .html for a webpage and .jpg for a JPEG image. Renaming the ending alone does not convert the contents.

Saving versions

Save a working version before a major change. With Git, commit a small set of related edits and describe what changed so you can find that version later.

What a repository is

A repository holds a project’s files and change history. A README explains how to use the project. Commits mark changes you can inspect later.

Static websites

A static host sends files such as HTML, CSS and JavaScript. The browser can still run interactive code, like a quiz or a small model, after those files arrive.

HTML and CSS

HTML gives a page its structure, such as headings and buttons. CSS controls appearance and layout. JavaScript can add behavior when you press a button.

Debugging

Try the smallest input that triggers the problem. Write down what you expected, then check the actual values one step at a time until they diverge.

Pseudocode

Write the steps without worrying about syntax. For a score counter: start at zero, read each result, add one for a win, then display the total.

Testing software

Choose an input and write the expected result before running it. Try a typical case, an empty input and a boundary case. If you fix a bug, rerun the input that exposed it.

Learning from examples

During training a model makes a prediction, measures the error and adjusts numbers called weights. Separate practice examples from test examples to check whether it learned patterns that generalize.

Generating text

A language model estimates which piece of text might come next. It picks one, adds it to the context and repeats. This can produce a sentence the model never saw as a whole.

Overfitting

A model can learn details that work only on its training set. Test it on independently written examples. A large training-to-test performance gap is one clue to investigate.

Game practice routines

Choose one skill, such as tracking a moving target. Do a short repeatable drill, play one round focusing on it, and note one thing to change next time.

Creative game ideas

Pick one action, one obstacle and one win condition. For example: steer a bouncing ball, dodge moving gates and reach three checkpoints. Prototype that before adding more features.

MVPs

Choose one person, one problem and one working feature. For a homework planner, a list with due dates might be enough to test whether someone actually uses it.

Customer interviews

Ask about the last time the problem happened. What did they do, how long did it take and what was frustrating? Concrete stories tell you more than asking whether an idea sounds cool.

Project pitches

Describe who it helps, the problem and what the person can do with it. End with a short example or demonstration.

Naming a project

List words describing the goal and the audience. Pair two, say each candidate aloud and see whether someone can spell it after hearing it once.

Feedback

Point to one specific detail, say what effect it had, then suggest one change. For example: the button label helped me start, but I couldn't find the back button.

Group projects

List the deliverables, give each one an owner and agree on a check-in before the deadline. Leave time for everyone to review the combined result.

Summarizing

Name the main idea in one sentence. Add only the details needed to understand it. Check that the summary keeps the author’s meaning and uses your own wording.

Quoting evidence

Introduce who is speaking, copy the relevant words exactly and give the citation your teacher requested. Follow it with your explanation of how the quote supports your point.

Proofreading

Read once for meaning, once for sentence boundaries and once for spelling. Reading aloud slowly can reveal a missing word your eyes skipped.

Note taking

Use a short heading for each idea. Write a key point in your own words, add one example, and mark anything you need to ask about later.

Giving a presentation

Build the talk around one message. Use slides to show a useful example or image, and rehearse aloud with a timer. Practice the opening and closing separately.

Emailing a teacher

Use a subject that names the assignment. In the message, explain what you tried, ask one specific question, then sign your name.

Fractions

Use a common denominator before adding. For example, one half plus one third becomes three sixths plus two sixths, which equals five sixths.

Ratios

A ratio compares amounts in order. Two red beads for every three blue beads scales to four red and six blue when you double both amounts.

Rectangle area

Multiply length by width using the same unit for both. A rectangle 4 cm by 7 cm covers 28 square centimeters.

Circle area

Multiply pi by the radius squared. For radius 3 cm, the area is 9 pi square centimeters, about 28.27 square centimeters.

Perimeter

Add the lengths of all outer sides. A rectangle 4 meters by 7 meters has perimeter 4 + 7 + 4 + 7 = 22 meters.

Unit conversions

One meter equals 100 centimeters. Multiply meters by 100 to get centimeters. Divide centimeters by 100 to get meters.

Reading graphs

Read the title and axis labels first. Check what one tick means and whether the scale starts at zero. Then compare the values the graph actually shows.

Elapsed time

Count forward in easy jumps. From 3:45 to 5:10, count 15 minutes to 4:00, one hour to 5:00 and ten minutes more: 1 hour 25 minutes.

Probability

When outcomes are equally likely, divide the number of favorable outcomes by the total number. Rolling an even number on a fair six-sided die has probability three sixths, or one half.

Shadows

A shadow forms when an object blocks light. When the Sun is low in the sky, its rays hit the ground at a shallow angle and a standing object's shadow stretches farther.

Echoes

Sound travels to a surface and reflects. If the reflected sound reaches you late enough to hear it separately, you hear an echo.

Condensation

Water vapor in the surrounding air cools against the cold glass. Some turns into liquid droplets on the outside.

Evaporation

Some water molecules at the surface escape into the air. Moving air helps wet clothes dry by carrying away humid air near the fabric.

Floating

Water pushes upward on an object. A floating boat displaces enough water for that upward force to balance its weight. Its hollow shape helps it displace a lot of water.

Day and night

Earth rotates. Your location turns toward the Sun for daylight and away from it for night. This rotation makes the Sun appear to move across the sky.

Stars twinkling

Starlight passes through moving layers of air with different temperatures. These layers bend the light by changing amounts, making a distant star appear to flicker.

Rhythm practice

Set a slow, comfortable beat and tap once per click. Count groups of four aloud. Speed up only when the beat feels even.

Photo composition

Imagine a three-by-three grid. Try placing the subject near a grid intersection, check the edges for distractions, then try a centered shot and compare the two.

Steady video

Hold the phone with two hands, keep your elbows close and start recording before the action. For a still shot, rest the phone on a stable surface.

Story structure

Give a character a goal, put a specific obstacle in the way and let a choice change what happens. End by showing a consequence of that choice.

Packing a bag

Check tomorrow’s schedule. Pack the books and materials you actually need, place completed work in one folder, and keep frequently used items in an accessible pocket.

Tidying a desk

Clear one section. Put items you use daily within reach, gather loose papers in one place and give everything else a home before moving to the next section.

Shopping lists

Check what you already have, write down what is missing and group it by store section. Put quantities beside anything where the amount matters.

Following a recipe

Read the full recipe first. Gather the ingredients and tools, check the amounts and lay out ingredients in the order you will use them.

Making plans with a friend

Suggest one activity and a specific time. Make it easy to offer another option: “Want to play on Saturday afternoon? Sunday works for me too.”

Choosing between options

Choose two or three criteria you care about and compare each option against the same criteria. If the decision is reversible, a small trial can answer more than guessing.
