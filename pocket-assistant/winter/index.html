Starting homework

Pick one assignment. Open it and write down the smallest thing you can do next, such as reading the first question. Set a five-minute timer and do just that step. When it rings, decide on the next one.

Writing a paragraph

Write your main point in one sentence. Add one detail or quote that supports it, then explain how that detail proves your point. Read the sentences together and check that each one helps explain the same idea.

Planning your day

Start with commitments that already have a time. Pick the one remaining task that matters most and give it a time slot. Leave a little space between tasks in case one takes longer.

Ideas for boredom

Try a ten-minute challenge: photograph three ordinary objects so they look unusual, draw a map of a made-up place, or invent a game using only paper and a coin.

How rain forms

Water evaporates from surfaces and enters the air as vapor. When moist air cools, some vapor condenses into cloud droplets. Droplets can join and grow heavy enough to fall as rain.

Why the sky looks blue

Sunlight contains many colors. Air molecules scatter shorter wavelengths, including blue, more strongly than longer wavelengths like red. That scattered light reaches your eyes from all across the sky.

Changing seasons

Earth's axis is tilted. When your hemisphere tilts toward the Sun, sunlight hits it more directly and the days are longer. Six months later, the other hemisphere tilts toward the Sun.

Moon phases

The Sun lights roughly half of the Moon. As the Moon orbits Earth, we see different amounts of that sunlit half. A crescent means only a narrow slice of the lit side faces us.

Percent of a number

Percent means out of 100. To find a percentage of a number, divide the percentage by 100 and multiply by the number. For example, 15 percent of 80 is 0.15 times 80, which is 12.

Sale prices

For a 20% discount, you pay 80% of the original price. Multiply the original price by 0.80. For example, a $30 item costs $24 before tax.

Finding an average

Add the values together and divide by how many values there are. For 6, 8 and 10, the sum is 24. There are three values, so the average is 8.

Wi-Fi and Ethernet

Wi-Fi sends data by radio between your device and router. Ethernet uses a cable. For gaming, Ethernet often gives more consistent timing because nearby wireless traffic and walls do not affect the cable.

What localhost means

Localhost points back to the device opening the link. If a friend opens your localhost address, their browser looks on their own device. A published website gives both of you a link to the same hosted files.

Storage and memory

Storage keeps files after an app closes. RAM holds the data an app is currently using. When you open a website, the browser uses RAM and may save files in its cache so the page loads faster next time.

Variables

A variable is a name that refers to a value. Assignment uses one equals sign. You can use the old value when calculating the new one.

Printing

Use print() to display values. Put text in quotes. You can pass several values separated by commas.

User input

Converting types

Use int() for whole numbers, float() for decimals, and str() for text. The text you convert must have a valid format for that conversion.

Strings

A string holds text. A slice like [1:4] takes characters at positions 1, 2 and 3. Counting starts at zero. upper() returns uppercase text.

Lists

A list holds items in order. Index 0 selects the first item. Index -1 selects the last one.

Appending items

Use append() to add one item to the end of an existing list. It changes the list in place.

For loops

A for loop takes one item at a time from a sequence. Indent every line you want to run for each item.

While loops

Range

range(start, stop, step) produces integers up to the stop value, excluding it. With one argument, counting starts at zero.

Conditionals

An if statement checks a condition. elif checks another condition if earlier checks failed. else handles the remaining cases.

Equality

Use == to test whether two values are equal. Use = to assign a value to a name.

Functions

Use def to define a function. Parameters receive values when you call it. A return statement sends a result back to the caller.

Return values

return ends a function call and passes a value back. print() displays a value. A function that reaches its end without returning a value gives the caller None.

Dictionaries

A dictionary maps keys to values. Use square brackets for a known key. Use get() with a default for a key that might be missing.

Indentation

Indentation groups lines into blocks. After a line such as if ready:, indent the lines that belong inside it. Four spaces per level is the usual style.

Index errors

IndexError means the requested position is outside the sequence. A list with three items has nonnegative indices 0, 1 and 2.

Name errors

NameError means Python could not find a name. Check spelling, capitalization and whether the assignment ran before the name was used.

Frame rate

FPS counts how many frames a game produces per second. At 60 FPS an evenly spaced frame takes about 16.7 milliseconds. Uneven timing can still look choppy.

Refresh rate

Hertz tells you how many times per second a display can refresh. A 120 Hz display can refresh 120 times each second; the game also has to supply frames.

Game latency

Ping usually measures a network round trip in milliseconds. A 30 ms result means the trip there and back took about 30 milliseconds. Spikes can matter as much as the average.

Bandwidth

Bandwidth is how much data a connection can carry per second. Eight megabits make one megabyte, so 80 Mbps is at most about 10 MB per second before overhead.

Screen resolution

Resolution gives the number of pixels across and down. A 2560 by 1440 image contains 3,686,400 pixels. Screen size determines how spread out they look.

Bookmarks

ZIP files

A ZIP archive bundles files together and can compress them. Extract it to get ordinary files you can open or edit individually.

File extensions

An extension is the ending after a filename’s final dot. It often identifies the format: .txt for plain text, .html for a webpage and .jpg for a JPEG image. Renaming the ending alone does not convert the contents.

Saving versions

Save a working version before a major change. With Git, commit a small set of related edits and describe what changed so you can find that version later.

What a repository is

A repository holds a project’s files and change history. A README explains how to use the project. Commits mark changes you can inspect later.

Static websites

HTML and CSS

Debugging

Testing software

Learning from examples

Generating text

A language model estimates which piece of text might come next. It picks one, adds it to the context and repeats. This can produce a sentence the model never saw as a whole.

Overfitting

A model can learn details that work only on its training set. Test it on independently written examples. A large training-to-test performance gap is one clue to investigate.

Ratios

A ratio compares amounts in order. Two red beads for every three blue beads scales to four red and six blue when you double both amounts.

Rectangle area

Multiply length by width using the same unit for both. A rectangle 4 cm by 7 cm covers 28 square centimeters.

Circle area

Multiply pi by the radius squared. For radius 3 cm, the area is 9 pi square centimeters, about 28.27 square centimeters.

Perimeter

Add the lengths of all outer sides. A rectangle 4 meters by 7 meters has perimeter 4 + 7 + 4 + 7 = 22 meters.

Unit conversions

One meter equals 100 centimeters. Multiply meters by 100 to get centimeters. Divide centimeters by 100 to get meters.

Elapsed time

Probability

When outcomes are equally likely, divide the number of favorable outcomes by the total number. Rolling an even number on a fair six-sided die has probability three sixths, or one half.

Shadows

A shadow forms when an object blocks light. When the Sun is low in the sky, its rays hit the ground at a shallow angle and a standing object's shadow stretches farther.

Echoes

Sound travels to a surface and reflects. If the reflected sound reaches you late enough to hear it separately, you hear an echo.

Condensation

Evaporation

Floating

Water pushes upward on an object. A floating boat displaces enough water for that upward force to balance its weight. Its hollow shape helps it displace a lot of water.

Day and night

Earth rotates. Your location turns toward the Sun for daylight and away from it for night. This rotation makes the Sun appear to move across the sky.

Stars twinkling

Starlight passes through moving layers of air with different temperatures. These layers bend the light by changing amounts, making a distant star appear to flicker.

A first-person narrator participates in or witnesses events and uses words like I and we. Look at the narration outside quoted dialogue.

Run-on sentences

Peer editing

Place value

Each position to the right is one tenth of the previous position. In 3.47 the 4 represents four tenths and the 7 represents seven hundredths.

Rounding

Find the tenths digit, then inspect the hundredths digit. Using the usual school rule, 4.76 rounds to 4.8 because the next digit is 6.

Comparing decimals

Line up the decimal points and append trailing zeros. Compare from the left: 0.50 exceeds 0.40 because five tenths exceeds four tenths.

Multiplying decimals

Multiply as whole numbers and put back as many decimal places as the factors have together. For example, 1.2 times 0.3 equals 0.36.

Dividing decimals

Multiply both numbers by the same power of ten until the divisor becomes a whole number. For example, 4.8 divided by 0.6 becomes 48 divided by 6.

Negative numbers

Farther right on a number line means greater. Minus three is to the right of minus eight and is closer to zero.

Absolute value

Absolute value measures distance from zero, so both −7 and 7 have absolute value 7.

Order of operations

Evaluate grouping first, then exponents, then multiplication and division left to right, then addition and subtraction left to right.

Exponents

A positive whole-number exponent counts factors. Three to the fourth means 3 × 3 × 3 × 3, which is 81.

Square roots

The principal square root of a nonnegative number is the nonnegative value whose square equals it. The square root of 49 is 7.

Prime numbers

A prime is a whole number greater than one with exactly two positive divisors: one and itself. For 29, testing primes up to its square root is enough.

Greatest common factor

List the factors both numbers share and select the largest. For 18 and 24, the greatest common factor is 6.

Least common multiple

List positive multiples until one repeats across both lists. For 4 and 6 the first common positive multiple is 12.

Simplifying fractions

Divide the numerator and denominator by their greatest common factor. For example, 18/24 divided top and bottom by 6 becomes 3/4.

Mixed numbers

Multiply the whole number by the denominator, add the numerator and keep the denominator. Three and two fifths becomes 17/5.

Median

Sort the data. Take the middle value for an odd count or average the middle two for an even count.

Mode

Count how often each value appears. The highest frequency determines the mode; a tie can give multiple modes.

Data range

Subtract the smallest observed value from the largest. For 4, 7 and 12, the range is 8.

Triangle area

Use half the base times its perpendicular height. With base 8 cm and height 5 cm, the area is 20 square centimeters.

Circle circumference

Circumference is pi times diameter, or twice pi times radius. A circle with diameter 10 cm has circumference about 31.4 cm.

Box volume

Multiply inside length, width and height in matching units. A 2 by 3 by 4 cm box has 24 cubic centimeters of interior volume.

Measuring angles

Place the center on the vertex and align one ray with zero. Read the scale starting at that zero where the other ray crosses.

Reading a ruler

Count the equal spaces between two numbered marks. Ten spaces in one centimeter mark millimeters. Start measuring from the zero mark.

Scale drawings

Estimating an answer

Round the inputs to easy nearby values and repeat the operation. Compare the order of magnitude and sign with your original result.

Split-screen games

Split-screen divides one display into views for local players. Check whether the particular game and mode support local multiplayer; online multiplayer alone doesn't guarantee it.

Input lag

Input lag is the time between a control action and the visible response. Try the display's game mode, test in an offline scene and change one setting at a time to separate display delay from network lag.

Controller dead zone

The dead zone ignores small movements near a stick's center. Lowering it can make tiny inputs register sooner; raising it slightly can mask drift, at the cost of fine control.

Stick drift

Stick drift means the controller reports movement even when the stick is centered. Test another game or a controller input screen. Compare a second controller if possible; a slightly larger dead zone can mask small drift.

Field of view

Field of view controls how much of the scene you can see. A wider view shows more around you but makes distant targets look smaller on the same screen.

Motion blur

Motion blur simulates smearing during fast movement. Toggle it in the same scene and turn the camera at the same speed to judge whether details are easier for you to follow.

Game subtitles

Subtitles usually show dialogue. Closed captions can also identify sounds or speakers. Check the game's accessibility settings for the available options.

Matchmaking

Matchmaking looks for available players that fit the mode's rules. Region, connection quality, party size, skill criteria and the number of people online can affect the wait.

Patch notes

Patch notes summarize changes such as bug fixes, balance adjustments or new features. Check the version and platform so you read the changes that apply to your game.

Minecraft crafting

A crafting table provides a three-by-three grid for recipes that don't fit in your inventory's two-by-two grid. Craft a table from four planks, place it and interact with it.

Minecraft survival and creative

Survival involves gathering resources and managing threats. Creative gives access to a large block inventory and flight, which makes it useful for trying a design before building it in Survival.

Keyboard switches

Linear switches move smoothly, tactile switches have a bump and clicky switches add an audible click. The keycaps and keyboard case affect the sound too.

Mouse DPI

DPI describes how many movement counts a mouse reports per inch of travel. Higher DPI usually moves the pointer farther at the same software sensitivity.

USB connectors

USB-C describes the connector shape. Cables and ports with that shape can support different charging power, data speeds and video features. Compare specifications for both ends.

Solid-state drives

An SSD stores files on flash memory. It can fetch data without moving a mechanical head, which helps games and apps load. Loading speed also depends on the rest of the device.

Operating systems

An operating system manages memory, files, devices and access for applications. iOS, Linux and Windows are examples.

Web browsers

A browser retrieves page resources, interprets their structure and styling, and can run JavaScript to make the page interactive.

Search engines

A search engine builds an index of pages and ranks matches to your search. Your browser is the app you use to visit the results.

Download versus upload

Uploading sends data from your device, such as backing up a video. Downloading brings data to your device, such as installing a game.

Airplane mode

Airplane mode turns off cellular communication. Wi-Fi and Bluetooth can often be enabled separately. A locally stored app can still work without internet.

Screenshots

A screenshot saves a still image of the visible screen. Crop out unrelated details before sharing; use a recording when the order of actions matters.

Screen recordings

A screen recording captures a sequence of actions as video. Start just before the bug, repeat it once and stop so someone can see the exact sequence.

Cropping a photo

Cropping selects the part of the image you keep. Move the frame around the subject and check the final shape before exporting a copy.

Aspect ratios

Aspect ratio is the width relative to height. A 16:9 clip on a differently shaped screen needs bars, cropping or stretching to fill the space.

Image compression

Compression encodes an image more efficiently. Lossless compression preserves its data; lossy compression can discard fine details to cut the file size further.

PNG versus JPEG

PNG is often useful for sharp graphics or transparency. JPEG often gives smaller photos, though heavy compression can create artifacts around edges.

Transparent backgrounds

Transparent pixels let the layer underneath show through. Many editors use a checkerboard to preview transparency; export to a format that supports it, such as PNG.

Vector graphics

Vector graphics describe paths and shapes mathematically. The renderer redraws them at the requested size rather than enlarging a fixed grid of pixels.

Pixels

A pixel is a sample in a digital image grid. Enlarging a small image reveals the limited detail stored in that grid.

Layers in an editor

Keep text, background and objects on separate layers. You can move or hide one element while preserving the others.

Audio tracks

Separate audio tracks let you lower music during speech and adjust each part independently. Listen through the transition before exporting.

Muting versus lowering volume

Mute silences a track while retaining its level setting. Lowering the level changes the balance you hear when the track plays.

Trimming a clip

Drag the clip's start or end point inward on the timeline. Preview the cut; many editors let you extend it again while the source file remains available.

Video timelines

The timeline arranges clips along time. Move a clip earlier or later, and use separate tracks for elements that should overlap.

Undo and redo

Undo reverses the last supported edit. Redo reapplies an edit you undid; making a new edit can discard the redo chain.

File paths

A path lists folders leading to a file. In school/science/report.txt, open school, then science, then report.txt.

Folder hierarchies

Choose one top-level folder per project, then a few subfolders such as photos, drafts and final. Keep naming consistent so you can predict where a new file belongs.

File backups

Keep a separate recoverable copy and test opening it. A backup with older versions can help if a bad change or deletion spreads to your current copy.

Syncing files

Sync keeps selected files aligned across devices. Changes and deletions may propagate, so check the service's trash and version history before making more edits.

Read-only access

Read-only access lets you view content while editing the original requires additional permission. Ask the owner for edit access if you need to change the shared version.

QR codes

A QR code stores encoded information such as text or a URL. Read the address preview before opening a link.

Browser tabs

A tab holds a page inside a browser window. Windows can each have their own set of tabs; close or group tabs by task to find the one you want.

Bookmarks folders

Create bookmark folders by purpose, such as school or projects. Give similar pages distinct names and remove links you no longer use.

Calendar reminders

Work backward from the event using travel and preparation time. Set the first reminder for when you must start getting ready.

Notification organization

Separate time-sensitive alerts from updates you can check later. Adjust each app's notification categories where available.

Say your name, mention what brought you there and ask one easy question about the shared activity.

Starting a conversation

Start with something you both experienced, such as a class project. Ask an open question and leave space for their answer.

Asking follow-up questions

Pick one detail they mentioned and ask about it. If they said they built a game, try “What part took the longest?”

Taking turns in conversation

Wait for a pause, refer to the point you are answering and keep your contribution short enough for others to join.

Clarifying a misunderstanding

Describe what you understood and ask if that was their meaning. A neutral question can clear things up before either person reacts.

Disagreeing respectfully

Name the point you agree on first if there is one. Explain your different reasoning and ask how they reached theirs.

Saying no to an invitation

Thank them for inviting you and give a clear answer. Suggest a different time only if you actually want to meet then.

Thank-you notes

Mention the specific gift or favor and why you appreciated it. A short sincere detail usually means more than a long generic message.

Borrowing something

Name the item, explain when you will return it and give the owner room to say no. Check before passing it to anyone else.

Returning something borrowed

Give it back on time in the condition you received it. If it is damaged or late, tell the owner directly and discuss how to put things right.

Introducing two friends

Say both names and offer one shared interest that can start a conversation. Let each person tell their own story.

Welcoming a newcomer

Introduce yourself, show them where things are and invite them into one specific activity. Offer a partner for the first drill.

Sharing credit

When showing the work, name what each person contributed. Give credit beside the relevant part so their role is clear.

Offering help

Asking for help

State the goal, what you tried and where the result differed from your expectation. Include one small example.

Listening actively

Let them finish, then briefly restate your understanding. Ask whether you got it right before offering advice.

Planning a meetup spot

Agree on one exact landmark, a time and a backup plan. “Inside the main entrance beside the map” is clearer than just “at the park.”

RSVPs

RSVP asks you to tell the host whether you will attend. Reply by the requested date and mention the event so the host can track responses.

Leaving a voicemail

Say who you are, why you called and what response you need. Repeat your callback details clearly if the person doesn't already have them.

Writing a clear text

Put the main request first. Include a time or place if needed, and reread it once for anything that could have two meanings.

Choosing a group activity

Narrow the options using real constraints such as time or distance, then vote or rotate who chooses.

Taking meeting notes

Record decisions, assigned tasks, owners and deadlines. You rarely need every sentence people said.

Setting an agenda

List the decisions you need and give each a time slot. Put unrelated ideas on a later list and end by confirming next steps.

Giving directions

Start from a known location, give turns in order and include visible landmarks at confusing points. Mention the destination's entrance.

Being a good spectator

Cheer effort and good play, follow the venue's rules and let the coaches give instructions. Treat officials and both teams respectfully.

Sketching with shapes

Break the object into a few circles, boxes or cylinders. Adjust their relative sizes before drawing details.

Contour drawing

A contour follows the visible edges and changes of shape. Look at the object frequently and draw slowly enough to notice small turns.

Shading a sphere

Choose a light direction. Leave the light-facing area bright, shade progressively around the curve and add a cast shadow on the opposite side.

One-point perspective

For one-point perspective, set a horizon line and one vanishing point. Parallel edges going directly away from you aim toward that point.

Mixing paint colors

Start with a small amount of the lighter color. Add the stronger color a little at a time and test a swatch before mixing a large batch.

Warm and cool colors

Reds, oranges and yellows often feel warm; blues and some greens feel cool. Nearby colors change how warm a particular shade appears.

Complementary colors

Complementary colors sit opposite each other on a chosen color wheel. On a traditional artist's wheel, blue and orange are a pair.

Negative space

Negative space is the area around and between objects. Sketching those shapes helps check proportions.

Tracing versus freehand

Tracing follows an existing outline. Freehand drawing builds the shapes yourself using observation or imagination; each exercises a different skill.

Keeping a sketchbook

Choose one nearby object and draw it from three angles. Date the page and note one detail you noticed on the second try.

Paper collage

Lay out the largest shapes first, overlap smaller pieces and take a photo of the arrangement before gluing.

Folding a paper airplane

Fold along a clear centerline and match wing edges and angles. Check the plane from the front for uneven bends.

Origami creases

Align the corners before pressing. Hold them in place, then crease from the center outward on a flat surface.

Lettering a title

Mark the midpoint of the space and sketch the word lightly with room for each letter. Adjust spacing before darkening it.

Designing a logo

Sketch one simple silhouette based on the main idea. Shrink your sketch to icon size to check that it stays recognizable.

Making a comic strip

Give each panel one visible moment or change. Thumbnail the sequence and leave space for dialogue before drawing the final art.

Storyboarding

Draw rough frames in order. Under each, note the action, camera position and sound so you know what to capture.

Character goals

Give the character a specific goal, a reason it matters and an obstacle that forces a choice. Show progress or a setback in each scene.

Writing dialogue

Give each speaker a different priority and rhythm. Read the scene aloud and remove lines that only explain things both characters know.

Describing a setting

Choose a few concrete details the character would notice, such as a sound or an object in use. Let the details affect what happens.

Writing a haiku

Focus on one observed moment and a shift in what you notice. If your assignment requests a 5–7–5 syllable pattern, count and revise after drafting.

Rhymes

Rhymes share ending sounds, especially from the stressed vowel onward. Listen to the words aloud rather than judging spelling alone.

Melody

The melody is the sequence of pitches and rhythms heard as a tune. Try humming the main line while ignoring the backing instruments.

Chords

A chord combines notes sounding together as harmony. A melody is a sequence of notes unfolding over time.

Playlists

Decide the mood you want at the beginning and end. Put songs with related energy near each other and listen to each transition.

Reading a compass rose

Find the compass rose or north arrow. Rotate the map to match your surroundings if that makes the route easier to follow.

Map legends

The legend pairs each color, line or symbol with its meaning. Check it before assuming a dashed line is a road or trail.

Contour lines on maps

Each contour connects points at the same elevation. Closely spaced contours usually indicate a steeper slope; read the interval to see the height difference.

Latitude

Latitude gives angular distance north or south of the equator, from zero to ninety degrees. Lines of equal latitude run east–west.

Longitude

Longitude gives angular distance east or west of the prime meridian. Together with latitude it locates a point on Earth.

Time zones

Different regions use different standard clock times as Earth rotates. Check both places and the date when scheduling, because seasonal clock changes can differ.

Continents

A continent is a major geographic land region. A country is a political territory; one continent can include many countries.

Islands

An island is land surrounded by water on all sides. It can lie in an ocean, lake or river.

Peninsulas

A peninsula has water on most sides while remaining connected to a larger landmass. On a map, look for the land connection.

Archipelagos

An archipelago is a group or chain of islands. The islands can vary widely in size.

Lakes versus ponds

Both are inland bodies of water. Lakes are often larger or deeper, but there is no single size cutoff used everywhere.

River tributaries

A tributary is a stream or river that flows into another stream or river. Follow the direction of flow to identify which joins which.

River deltas

A river slows as it enters a larger body of water and can deposit sediment. If it accumulates, the deposits build a delta.

Watersheds

A watershed is the area draining toward a shared outlet. Ridges often separate water flowing to different streams.

Tides

The Moon's gravity and, to a lesser extent, the Sun's produce tides. Coastline shape and local geography affect their timing and height.

Ocean waves

Wind transfers energy to the water surface. Wave size depends on wind speed, how long it blows and how far it travels over open water.

Sand dunes

Wind moves loose sand. When sand collects around an obstacle or the wind slows, a mound can grow; vegetation can help stabilize it.

Erosion

Erosion moves sediment or rock away by water, wind, ice or gravity. Look for both a source of material and the place it collects.

Weathering

Weathering breaks down or changes rock in place. Erosion carries the resulting material elsewhere.

Cloud cover

Cloud cover describes how much of the visible sky is covered. Overcast means nearly or completely covered; cloud cover alone does not tell you whether rain will fall.

Humidity

Relative humidity compares the vapor present to the amount air can sustain at its current temperature. Cooling air can raise relative humidity even without adding water.

Wind direction

A north wind comes from the north and blows toward the south. Weather reports name winds by their origin.

Rainbows

Sunlight bends as it enters droplets, reflects inside and bends again as it leaves. Different wavelengths bend by different amounts, separating the colors.

Dew

Dew forms when a surface cools enough for nearby water vapor to condense on it. This often happens overnight as the ground loses heat.

Frost

Frost can form when a surface is cold enough for water vapor to deposit as ice. A ground surface can be colder than the reported air temperature.

Dribbling a soccer ball

Use small touches when space is tight and longer ones in open space. Practice changing direction around a marker while keeping the ball within a step.

Soccer throw-ins

A throw-in goes to the opponents of the last player to touch the ball before it crossed the touchline. Face the field and use both hands from behind and over the head, with part of each foot on or outside the line.

Corner kicks

When the whole ball crosses the goal line off a defender without a goal, the usual restart is a corner kick for the attacking team.

Goal kicks

When the whole ball crosses the goal line off an attacker without a goal, the usual restart is a goal kick for the defending team.

Soccer offside

Officials judge position when a teammate plays or touches the ball. In the opponents' half, being nearer the goal line than both the ball and the second-last opponent can put you offside; interfering with play or an opponent matters too.

Soccer formations

In a 4-3-3, the ten outfield players are grouped as four defenders, three midfielders and three forwards. The goalkeeper is counted separately.

Soccer assists

An assist credits a player for helping set up a teammate's goal, often with the final pass. The exact statistical rule varies by competition.

Soccer halftime

Halftime separates the two periods and gives teams a break and a chance to adjust tactics. They normally change ends for the second half.

Basketball rebounds

A rebound is gaining possession after a missed shot. The shooting team's rebound is offensive; the opposing team's is defensive.

Basketball traveling

Traveling is illegal foot movement while holding the ball. The call depends on gathering the ball, establishing a pivot foot and what the player does next.

Basketball assists

A basketball assist is a pass judged to lead directly to a made basket. A long series of independent moves by the scorer can change the ruling.

Basketball free throws

A free throw is an unguarded attempt from the free-throw line worth one point if made. The foul and game situation determine the number of attempts.

Tennis scoring

In a standard game points go love, 15, 30, 40, then game. At 40–40, called deuce, a player normally needs two consecutive points to win.

Tennis doubles

Doubles has two players per team and uses the wider doubles sidelines during rallies. The serve still lands in the diagonal service box.

Volleyball rotation

In standard indoor volleyball, the receiving team rotates one position clockwise when it wins the right to serve. Winning another point while already serving doesn't trigger a rotation.

Badminton rallies

A rally is the exchange starting with the serve and ending when the shuttle is out of play. Each side tries to land it in the opponent's court or force a fault.

Relay races

Relay teammates cover separate legs in order. In baton events, the exchange must happen inside the designated zone.

Personal bests

A personal best is your best recorded result for a particular event. Compare the same distance and conditions when interpreting progress.

Tournament brackets

Read a bracket from the opening matches toward the final. In single elimination each loser exits and each winner advances along the connecting line.

Round-robin tournaments

In a single round robin, every team meets every other team once. With six teams each plays five games, giving fifteen matches in total.

Keeping score

Agree on the scoring rules first and record each point or scoring play as it happens. Confirm the running total at natural breaks.

Practicing a weak foot

Start with short stationary passes against a target using the weaker foot. Increase distance or movement after the direction becomes consistent.

Bicycle gears

A lower gear needs less force per pedal stroke but travels less distance per turn. Shift before a steep section when possible and ease pedal pressure during the change.

Bicycle frame sizes

Wheel diameter describes the wheel. Frame dimensions and geometry affect reach and riding position. Check the maker's sizing chart and how the bike fits you.

BMX pegs

Pegs are short extensions mounted near the axles on compatible BMX bikes. Their fit depends on axle size, hub hardware and intended use.

Mirrors

A smooth mirror reflects rays in predictable directions. Your eyes trace the reflected rays back and perceive a virtual image behind the surface.

Refraction

Light changes direction as it crosses between water and air at an angle. Your eyes interpret the submerged portion as coming from a different position.

Magnifying glasses

A converging lens held close enough to the object produces an enlarged virtual image. Adjust its distance until the letters look sharp.

Color filters

A colored filter transmits some wavelengths more strongly than others. Its effect also depends on which wavelengths are present in the incoming light.

Pitch

Pitch mainly follows frequency. Faster vibrations produce a higher pitch; increasing volume alone does not raise the note.

Loudness

Larger pressure variations generally sound louder. Distance from the source and the listener's sensitivity to different frequencies also matter.

Vibrating strings

A plucked string vibrates. Its motion transfers energy to the guitar body or a pickup system, and the resulting air vibrations reach your ears.

Static electricity

Rubbing can transfer electric charge to a balloon. That charge shifts nearby charges in the wall slightly, creating an attractive force.

Magnets

Like magnetic poles repel and unlike poles attract. Turn one magnet around to change which poles face each other.

Gravity

Earth's gravity pulls objects toward its center. Close to the surface, objects in free fall accelerate at roughly the same rate if air resistance is small.

Friction

Contact friction opposes sliding and transfers some mechanical energy into heat. A smoother or different surface can change how quickly the book slows.

Inertia

Inertia is the tendency to keep the same velocity until a net force changes it. When a bus brakes, a passenger's body tends to continue forward.

Levers

A lever pivots around a fulcrum. Applying force farther from the pivot increases its turning effect, trading a longer movement for less force.

Pulleys

A fixed pulley redirects tension, so pulling downward can lift upward. With a moving pulley, multiple supporting rope segments can reduce the force needed.

Gears

The teeth of two meshing external gears push each other, so they rotate in opposite directions. The gear with fewer teeth makes more turns.

Insulation

Insulation slows heat transfer. Trapped air or a vacuum reduces some transfer paths, and a lid limits exchange with the surrounding air.

Melting

Heat transferred into ice can let its molecules leave the ordered solid structure while remaining close together as liquid water.

Freezing

As water freezes under ordinary conditions, molecules arrange into a more open structure. The resulting ice occupies more volume than the same mass of liquid water.

Dissolving

Water molecules surround and disperse sugar molecules through the liquid. The sugar is still present, which is why the solution tastes sweet.

Mixtures

A mixture contains multiple substances combined physically. Its proportions can vary, unlike a pure compound with a fixed chemical composition.

Seed germination

Germination begins when suitable conditions let a seed resume growth. Water, oxygen and a suitable temperature are common requirements, and the root often emerges first.

Plant roots

Roots anchor the plant and absorb water and dissolved minerals. Some also store food reserves.

Photosynthesis

Plants use light energy to build sugars from carbon dioxide and water. The sugars supply material and energy for growth, and oxygen is released.

Pollination

Pollination is the transfer of pollen to a flower's receptive structure. Animals, wind or other mechanisms can carry it; pollination can enable seed formation.

Composting

Microorganisms break down suitable organic materials. A mix of moist scraps and dry leaves or paper, with air and some moisture, helps produce compost.

Reading a bus schedule

Choose the route, direction and correct day. Follow one trip's column or row from your boarding stop to the destination, checking the table headings.

Transfer stops

A transfer means leaving one vehicle and boarding another to finish the journey. Check the stop location, direction, wait time and applicable fare rules.

Round-trip tickets

A one-way ticket covers travel in one direction. A round trip includes an outbound and return journey subject to the operator's route and date conditions.

Packing for a day trip

Check the planned activity, weather and length of the outing. Pack what you will actually use and confirm tickets, directions and the return plan.

Checking a forecast

Look at the hourly forecast for the place and hours you will be outside. Compare temperature, precipitation chance and wind instead of relying only on the day's high.

Making an itinerary

Put fixed-time activities on the schedule first, group nearby stops and leave travel and waiting time. Decide which optional stop to skip if you run late.

Finding a library book

Find the call number in the catalog and check its section or location. Match the shelf-end labels, then compare the letters and numbers in order.

Library holds

A hold puts you in a queue or requests an available copy for pickup. Check the pickup location and wait for the ready notice before traveling.

Renewing a library loan

Renewal extends a loan if the library allows it. Check the updated due date; another reader's hold or a renewal limit may prevent an extension.

Comparing unit prices

Divide price by quantity in the same units for both packages. Compare the resulting price per ounce, item or other unit, then consider whether you will use the full package.

Reading a receipt

Compare each item's quantity and price with what you bought. Then check discounts, applicable tax and the final payment total.

Counting change

Count up from the price to the amount paid. From $13.65 to $14 is $0.35, then $6 to reach $20, so the change is $6.35.

Measuring furniture

Measure width, depth and height of the desk, plus the space and the delivery path. Include door openings, tight turns, drawers and room to sit.

Addressing an envelope

For a standard US envelope, put the recipient near the center, the return address at upper left and postage at upper right. Include the ZIP code.

Postcards

Write the recipient's full mailing address in the address area, put your message beside it and apply the correct postage. Check destination and postal requirements.

Reading a wall clock

The long hand gives minutes, five for each numbered step. The short hand indicates the hour it has passed; halfway from 3 to 4 with the minute hand on 6 means 3:30.

Using a checklist

Write short action items in the order you actually do them. Try the checklist once and adjust anything that was vague, missing or unnecessary.

Solving for x

Use inverse operations to isolate x. What you do to one side of the equation, do to the other. For 2x + 3 = 11, subtract 3 from both sides, then divide both sides by 2 to get x = 4.

Slope of a line

Slope is the steepness of a line: rise over run, or the change in y divided by the change in x. A slope of 2/3 means the line goes up 2 units when it goes right 3 units. A negative slope goes down as it goes right.

Linear equations

A linear equation graphs as a straight line. A common form is y = mx + b, where m is the slope and b is the y-intercept, the point where the line crosses the y-axis.

Inequalities

An inequality compares values with symbols such as <, >, ≤ or ≥. Solving one is like solving an equation, except that multiplying or dividing both sides by a negative number reverses the inequality sign.

Systems of equations

A system is two or more equations considered together. A solution is a set of values that makes every equation true. You can solve by graphing, substitution, or elimination, which adds or subtracts equations to cancel a variable.

The Pythagorean theorem

In a right triangle, a² + b² = c², where c is the hypotenuse, the side opposite the right angle, and a and b are the other two sides. If the legs are 3 and 4, the hypotenuse is 5.

Similar triangles

Similar triangles have the same shape but may differ in size. Their corresponding angles are equal, and corresponding sides are in the same ratio. You can use that ratio to find a missing side.

Volume of a cylinder

The volume of a cylinder is πr²h, the area of the circular base times the height. Use the same units for the radius and the height, and the result is in cubic units.

Volume of a sphere

The volume of a sphere is (4/3)πr³, where r is the radius, the distance from the center to any point on the surface. If you know the diameter, divide it by 2 first to get the radius.

Percent change

Percent change is the difference divided by the original amount, then multiplied by 100. A price that goes from $40 to $50 rises by 10/40, which is a 25 percent increase. A decrease uses the same formula and comes out negative or is called a decrease.

Proportions

A proportion says two ratios are equal, such as 2/3 = 4/6. To solve for a missing value, you can cross-multiply: if a/b = c/d, then a times d equals b times c.

Speed, distance and time

Speed equals distance divided by time. Distance equals speed times time, and time equals distance divided by speed. Use matching units, such as miles and hours if the speed is in miles per hour.

Graphing a line

Pick x-values, compute the matching y-values from the equation, and plot those points. For y = mx + b, start at the y-intercept, then use the slope to find another point: rise the numerator and run the denominator.

The distributive property

The distributive property says a(b + c) = ab + ac. Multiply the factor outside the parentheses by each term inside, and keep each term's sign. For example, 3(x + 4) = 3x + 12.

Combining like terms

Like terms have the same variable raised to the same power, such as 3x and 5x. Add or subtract their coefficients and keep the variable part: 3x + 5x = 8x. Constants combine with constants, and 3x and 3x² are not like terms.

Scientific notation

Scientific notation writes a number as a value between 1 and 10 multiplied by a power of 10. 5,400 is 5.4 × 10³, and 0.0032 is 3.2 × 10⁻³. A positive exponent means a larger number; a negative exponent means a fraction less than 1.

Independent events

Two events are independent if one outcome does not change the probability of the other, such as two flips of a fair coin. For independent events, multiply their probabilities: the chance of heads then heads is 1/2 × 1/2 = 1/4.

The scientific method

The scientific method is a way to test ideas: ask a question, form a hypothesis, plan a fair test, collect data, and draw a conclusion. Other people should be able to repeat the test to see if they get similar results.

Hypotheses and theories

A hypothesis is a testable possible explanation for something you observed. A scientific theory is a well-supported explanation built from many tested hypotheses and a large body of evidence, not a guess. Theories can still be revised if new evidence appears.

Atoms

An atom is the basic unit of a chemical element. It has a nucleus of protons and neutrons, with electrons around the nucleus. The number of protons, called the atomic number, identifies the element.

Molecules

A molecule is two or more atoms bonded together. The atoms can be the same, as in O₂, or different, as in water, H₂O. The chemical formula tells you which atoms are in the molecule and how many of each.

The periodic table

The periodic table organizes elements by atomic number. Rows are called periods and columns are called groups. Elements in the same group often have similar chemical properties, such as the noble gases in the far-right column.

States of matter

The common states of matter are solid, liquid and gas. In a solid, particles are packed in a fixed shape. In a liquid they flow and take the shape of the container. In a gas they spread out to fill the available space. Heat or pressure can change the state.

Density

Density is mass divided by volume. A material with higher density has more mass in the same amount of space. That is why a steel bolt sinks in water while a larger piece of wood can float: steel’s density is greater than water’s, and most wood is less dense than water.

Acids and bases

Acids and bases are opposite kinds of substances in water. Acids increase hydrogen ion concentration and often taste sour, such as lemon juice. Bases decrease that concentration or increase hydroxide, and many feel slippery, such as soap. They can neutralize each other.

pH

pH is a scale that usually runs from 0 to 14 and measures how acidic or basic a water solution is. 7 is neutral, like pure water. Numbers below 7 are acidic and numbers above 7 are basic. Each step of 1 is a tenfold change in acidity.

Chemical versus physical change

A physical change alters form but not the substance itself, such as melting ice or tearing paper. A chemical change makes a new substance, such as burning wood or baking a cake. Clues can include a new color, gas, temperature change or unexpected solid, though those clues are not proof by themselves.

Animal and plant cells

Both animal and plant cells have a nucleus, cytoplasm and a cell membrane. Plant cells also have a cell wall and usually chloroplasts for photosynthesis, and they often have a large central vacuole. Animal cells do not have a cell wall or chloroplasts.

DNA

DNA is the molecule in cells that carries genetic instructions. It is shaped like a double helix, a twisted ladder, with paired bases: A with T, and C with G. Those instructions help determine how an organism grows and how its cells work.

Food chains

A food chain shows how energy moves from one living thing to another. It often starts with a producer, such as a plant, that makes its own food. A consumer eats plants or other animals, and a decomposer breaks down dead material. Arrows point toward the eater, the direction energy flows.

Ecosystems

An ecosystem is a community of living things plus the nonliving parts of their environment, such as water, soil, air and climate. A change in one part, like a drought or the loss of a species, can affect many other parts.

The water cycle

The water cycle is the movement of water between Earth’s surface and the atmosphere. Water evaporates, condenses into clouds, and falls as precipitation. It can then flow as runoff, soak into the ground, or evaporate again.

The solar system

The solar system is the Sun and everything that orbits it, including eight planets, moons, asteroids and comets. The four inner planets are rocky. The four outer planets are much larger and are mostly gas and ice. Gravity from the Sun keeps the planets in orbit.

Solar and lunar eclipses

A solar eclipse happens when the Moon passes between the Sun and Earth and the Moon’s shadow falls on Earth. A lunar eclipse happens when Earth passes between the Sun and the Moon and Earth’s shadow falls on the Moon. They do not occur every month because the Moon’s orbit is tilted.

Plate tectonics

Earth’s outer shell is broken into large plates that move slowly over the mantle. Where plates meet they can pull apart, collide, or slide past each other. That movement helps explain earthquakes, many volcanoes, and the building of mountain ranges.

Earthquakes

An earthquake is the shaking caused when rocks along a fault suddenly slip and release energy as seismic waves. Most earthquakes occur near tectonic plate boundaries. During shaking, drop to the ground, take cover under sturdy furniture, and hold on until it stops.

Volcanoes

A volcano is an opening where molten rock, ash and gas can reach the surface. Most volcanoes form near plate boundaries, especially where a plate sinks or where plates pull apart. Magma is molten rock underground; once it reaches the surface it is called lava.

Fossils

Fossils are remains or traces of past life, such as bones, shells, footprints or leaf impressions, preserved in rock. They form more often when an organism is buried quickly and hard parts are slowly replaced or left as an imprint. Fossils help scientists learn how life and environments have changed.

Acceleration

Acceleration is the rate of change of velocity. An object accelerates if it speeds up, slows down, or changes direction. In everyday use people often say acceleration only for speeding up, but in physics all of those changes count.

Kinetic and potential energy

Kinetic energy is the energy of motion. Potential energy is stored energy because of position or condition, such as a bike at the top of a hill or a stretched spring. Energy can change from one form to the other, like a ball slowing as it rolls uphill and speeding up as it comes down.

Simple circuits

A simple electric circuit is a closed loop that lets current flow from a power source through a load, such as a bulb, and back again. If the loop is broken, the current stops. A switch opens or closes the loop, and wires need a complete path of conductive material.

Electrical conductors

An electrical conductor lets electric current flow easily. Metals such as copper and aluminum are common conductors and are used in wires. An electrical insulator, such as rubber, glass or many plastics, resists current and is used to coat wires for safety.

The greenhouse effect

The greenhouse effect is the way some gases in the atmosphere, including carbon dioxide and water vapor, absorb heat and keep Earth warmer than it would be without them. A stronger greenhouse effect from extra greenhouse gases traps more heat and raises global average temperatures.

Renewable energy

Renewable energy comes from sources that are naturally replenished, such as sunlight, wind, moving water and geothermal heat. Fossil fuels like coal, oil and natural gas form much more slowly than we use them. Renewable sources still have costs, land use and other tradeoffs, but they do not run out in the same way.

Recycling

Recycling turns used materials into new products instead of throwing them away. Rinse containers, follow your local rules, and keep items loose rather than bagged unless your collector says otherwise. Not everything with a recycling symbol is accepted curbside, so check the local list.

The atmosphere

Earth’s atmosphere is the layer of gases around the planet. It is mostly nitrogen and oxygen, with smaller amounts of argon, carbon dioxide and other gases. It provides air to breathe, helps protect the surface from much of the Sun’s harmful radiation, and is where weather happens.

Microscopes

A microscope magnifies things that are too small to see clearly with your eyes alone. A compound light microscope uses lenses and light; start on the lowest power, use the coarse knob to find the specimen, then sharpen with the fine knob. Keep slides thin and never use the coarse knob on high power.

The human heart

The heart is a muscle that pumps blood through the body. The right side sends blood to the lungs to pick up oxygen. The left side sends oxygen-rich blood to the rest of the body. Valves keep blood moving in one direction.

The lungs

The lungs are where oxygen enters the blood and carbon dioxide leaves it. When you inhale, air travels down the windpipe to smaller airways and into tiny air sacs called alveoli. Oxygen crosses into the blood there, and carbon dioxide crosses out to be exhaled.

Digestion

Digestion breaks food into nutrients the body can absorb. It starts in the mouth with chewing and saliva, continues in the stomach, and most nutrient absorption happens in the small intestine. The large intestine absorbs water and forms leftover material into stool.

The American Revolution

The American Revolution was the war in which the 13 colonies broke away from Britain and became the United States. Fighting began in 1775 and ended with the Treaty of Paris in 1783, which recognized American independence.

The Declaration of Independence

The Declaration of Independence, adopted on July 4, 1776, announced that the 13 colonies were separating from Britain. It says that people have rights such as life, liberty and the pursuit of happiness, and it lists complaints against the British king. Thomas Jefferson was its main author.

The U.S. Constitution

The U.S. Constitution is the supreme law of the United States. Written in 1787, it sets up the national government, divides power among branches and states, and describes the rights of the people, including later amendments.

The three branches of government

The U.S. federal government has three branches. Congress, the legislative branch, makes laws. The president and the executive branch carry out laws. The courts, the judicial branch, interpret laws and the Constitution.

How a bill becomes a law

A bill is introduced in the House or Senate, studied in committee, and must pass both chambers in the same form. The president can sign it into law or veto it. Congress can override a veto with a two-thirds vote in both the House and the Senate.

The Bill of Rights

The Bill of Rights is the first ten amendments to the U.S. Constitution, ratified in 1791. It protects freedoms such as speech, religion, the press, assembly and petition, and it also covers rights such as a jury trial and protection from unreasonable searches.

Voting in the United States

In the United States, citizens who are 18 or older can vote once they meet their state's registration rules. People vote in local, state and federal elections. Rules about registration, ID and early or mail voting vary by state, so check your state or local election office.

The Electoral College

The Electoral College is the system used to elect the U.S. president. There are 538 electors, and a candidate needs at least 270 electoral votes to win. Each state's electors usually equal its members of Congress. In most states, the candidate who wins the statewide popular vote gets all of that state's electors.

The Civil War

The American Civil War was fought from 1861 to 1865 between the Union and the Confederate states that had seceded. Slavery and its expansion were at the center of the conflict. The Union won, and the 13th Amendment abolished slavery in the United States.

The civil rights movement

The civil rights movement of the 1950s and 1960s was a struggle to end legal racial segregation and protect equal rights for Black Americans. It included court cases, boycotts, sit-ins, marches and new laws such as the Civil Rights Act of 1964 and the Voting Rights Act of 1965.

World War I

World War I lasted from 1914 to 1918 and was fought mainly in Europe between the Allied Powers and the Central Powers. The United States entered in 1917 on the Allied side. An armistice on November 11, 1918, ended the fighting.

World War II

World War II lasted from 1939 to 1945 and was fought between the Allies and the Axis powers, including Nazi Germany, Italy and Japan. The United States entered after Japan attacked Pearl Harbor on December 7, 1941. The war in Europe ended in May 1945, and Japan surrendered in September 1945.

The Industrial Revolution

The Industrial Revolution was a period when many goods began to be made by machines in factories instead of by hand. It began in Britain in the 1700s and spread to other countries. Steam power, new machines and later electricity changed work, cities and transportation.

Ancient Egypt

Ancient Egypt was a civilization along the Nile River in northeast Africa. It is known for pharaohs, pyramids, hieroglyphic writing and a religion that included many gods and a strong focus on the afterlife. The Nile's yearly flooding helped farming in a desert region.

Ancient Rome

Ancient Rome began as a city in Italy, became a republic, and later an empire that controlled much of Europe, North Africa and the Middle East. Roman law, roads, Latin and republican ideas influenced later governments. The Western Roman Empire fell in 476 CE.

Ancient Greece

Ancient Greece was made up of city-states such as Athens and Sparta, rather than one single country. Athens is known for an early form of democracy, and Greek thinkers, writers and athletes influenced later science, government, theater and the Olympic Games.

The Silk Road

The Silk Road was a network of trade routes that linked East Asia with Central Asia, the Middle East and the Mediterranean for many centuries. Merchants traded goods such as silk, spices and metals, and the routes also spread ideas, technologies and religions.

The Supreme Court

The Supreme Court is the highest court in the United States. It has nine justices who are nominated by the president and confirmed by the Senate, and they can serve for life. The Court interprets the Constitution and can strike down laws that conflict with it.

Constitutional amendments

A constitutional amendment is a formal change to the U.S. Constitution. There are 27 amendments so far. The usual process is a two-thirds vote in both houses of Congress, then approval by three-fourths of the states.

Checks and balances

Checks and balances are ways each branch of the U.S. government can limit the others so that one branch does not become too powerful. Examples include the president's veto, Congress overriding a veto, the Senate confirming appointments, and the courts reviewing laws.

The Great Depression

The Great Depression was a severe worldwide economic downturn that began in the United States after the stock market crash of 1929. Many people lost jobs, homes and savings. In the U.S., President Franklin D. Roosevelt's New Deal created programs to provide relief and reform the financial system.

The moon landing

On July 20, 1969, NASA's Apollo 11 mission landed the first humans on the Moon. Neil Armstrong and Buzz Aldrin walked on the lunar surface while Michael Collins stayed in orbit in the command module. Armstrong's first words included, "That's one small step for a man, one giant leap for mankind."

Metaphor and simile

A simile compares two things using like or as, such as "the cloud was like a cotton ball." A metaphor says one thing is another to make a comparison, such as "the cloud was a cotton ball." Both are figures of speech, but only a simile uses like or as.

Plot

Plot is the sequence of events in a story. Many stories move from exposition, where the setup is introduced, through rising action and a climax, then falling action and a resolution. The conflict, the main problem the characters face, drives the plot forward.

Irony

Irony is when the result or meaning is the opposite of what was expected or said. Verbal irony is saying one thing and meaning another. Situational irony is when events turn out the opposite of what you would expect. Dramatic irony is when the audience knows something a character does not.

MLA citations

MLA style is often used in English and the humanities. A typical in-text citation is the author's last name and a page number in parentheses, such as (Lopez 12). At the end, a Works Cited list gives full details so a reader can find each source.

APA citations

APA style is often used in the social sciences. A typical in-text citation is the author's last name and the year, such as (Lopez, 2023). At the end, a References list gives full details for each source. Page numbers are added when you quote a specific passage.

Test-taking strategies

Read the directions and skim the test so you can budget your time. Answer the questions you know first, then return to harder ones. For multiple choice, try to think of the answer before looking at the options, and cross out choices you know are wrong. Check your work if time remains.

Making a study schedule

List upcoming due dates and exams, then break each subject into short study sessions across several days instead of one long cram. Put the hardest or earliest work first, include breaks, and leave a little buffer for things that take longer than expected.

Annotating a text

Annotating means marking a text as you read to help you understand it. Underline key claims, circle words to look up, and write short notes or questions in the margin. Mark only the most useful parts so the page stays readable.

Writing an essay outline

An outline is a plan for your essay. Start with your thesis, then list each body paragraph's main point and the evidence you will use. Add a note for the introduction and conclusion. A clear outline makes the draft faster and helps you stay on topic.

Introductions and conclusions

An introduction should present the topic and end with your thesis, the main claim the essay will support. A conclusion should not just copy the introduction. It should tie the points together and leave the reader with the significance of your argument, without adding a major new claim.

Avoiding plagiarism

Plagiarism is presenting someone else's words or ideas as your own. Put borrowed wording in quotation marks, cite the source, and paraphrase in your own words instead of only swapping a few terms. When you are unsure, cite. Your school's policy explains the rules and consequences.

Do Not Disturb

Do Not Disturb, or Focus modes on iPhone, can silence calls, alerts and notifications so you can sleep or work. You can usually allow repeated calls or notifications from chosen people. Check that it turns off when you want, or set a schedule so it does not stay on by accident.

AirDrop

AirDrop is Apple's way to send photos, files and links between nearby Apple devices over Wi-Fi and Bluetooth, without using a cable. Set AirDrop to receive from Everyone for a few minutes or only from Contacts, then turn it back if you do not want requests from strangers.

iCloud

iCloud is Apple's cloud service for backing up an iPhone and syncing photos, files and settings across your Apple devices. A backup can help you restore a new or reset phone. Photos and files in iCloud count toward your storage plan, so check Settings if you run out of space.

Low Power Mode

Low Power Mode on iPhone reduces background activity and some visual effects to make the remaining battery last longer. Your phone may fetch mail less often and dim features until you charge it or turn the mode off. It is useful when you cannot charge soon, not as an everyday setting for everyone.

Find My

Find My can help you locate a missing iPhone, iPad, Mac or AirTag on a map, play a sound, or mark the device as lost. It works best when the device is powered on and connected, and when Find My was already turned on. A lost mode can lock the device and show a message with a contact number.

Offloading apps

Offloading an app removes the app from your phone but keeps its documents and data. You get the storage back that the app itself used, and you can reinstall it later without starting all over. Deleting an app can also remove its data, so offload if you think you will need that data again.

Screen Time

Screen Time on iPhone shows how long you use apps and can set limits, downtime or a passcode so a younger user cannot just change the rules. Use it to see where time goes and to set limits you actually want, and keep the passcode different from your device passcode if you are setting limits for yourself.

Restarting a frozen phone

If an iPhone is frozen, first try a regular restart: press and hold a volume button and the side button, then slide to power off, wait, and turn it back on. If the screen will not respond, use a force restart: quickly press volume up, then volume down, then hold the side button until the Apple logo appears.

Freeing phone storage

On iPhone, open Settings, then General, then iPhone Storage to see what is using space. Large videos, downloaded files and unused apps are common. Offload unused apps, delete videos you already backed up, and clear downloads in Safari or Files. Restart after large deletions if the free space has not updated yet.

Mobile hotspots

A mobile hotspot lets other devices use your phone's cellular data as Wi-Fi. It can use up data quickly and drain the battery, and some plans charge extra or cap hotspot data. Use a password, turn the hotspot off when you are done, and avoid it if you are low on data.

Screen mirroring

Screen mirroring shows your phone or computer display on a TV or monitor. AirPlay works with Apple devices and many compatible TVs, and some TVs or apps also support Chromecast or an HDMI cable. Both devices usually need to be on the same Wi-Fi network, except when you use a cable.

USB-C and Lightning

Lightning is Apple's older small charging connector used on many earlier iPhones. USB-C is a wider, reversible connector now used on newer iPhones, many Android phones, laptops and chargers. A cable has to match the ports on both ends, and charging speed also depends on the charger, not only the plug shape.

Strong passwords

A strong password is long, unique to that account, and hard to guess. A passphrase of several unrelated words is easier to remember than a short mix of characters. Use a different password for email and banking, and a password manager can store them so you do not reuse the same one everywhere.

Two-factor authentication

Two-factor authentication, or 2FA, asks for a second check after your password, such as a code from a text message or an authenticator app. It makes it much harder for someone who only has your password to get in. Keep backup codes in a safe place in case you lose your phone.

Phishing messages

A phishing message tries to trick you into sharing a password, code or payment, often by posing as a bank, school, store or delivery service. Check the real address, not just the display name, and do not tap unexpected links or share a login code. If you are unsure, open the official app or website yourself.

Private browsing

Private or Incognito browsing does not save your history, cookies or form entries on that device after you close the window. It does not make you invisible. Your school, workplace, internet provider or the sites you visit can still see activity, and downloads you save stay on the device.

Browser cookies

Cookies are small files a site stores in your browser to remember things such as a login, language or items in a cart. Some cookies also track visits across sites for advertising. You can usually block or clear cookies in browser settings, but you may have to log in again afterward.

VPNs

A VPN, or virtual private network, sends your internet traffic through an encrypted tunnel to a server, which can hide it from a local Wi-Fi network. It does not make you fully anonymous, and a poorly chosen VPN can see or mishandle your traffic. A VPN also will not fix a device that already has malware.

Software updates

Software updates fix bugs and close security holes, and they sometimes add features. Install updates from the official Settings app or app store, not from a random pop-up or text. Keep your phone plugged in or well charged, and back it up first if the update is a large system version.

Public Wi-Fi safety

Public Wi-Fi in cafes, airports and hotels is convenient but easier for others on the network to snoop if a site is not secure. Avoid logging into banking or entering passwords on unknown networks when you can use your phone's cellular data or a trusted VPN instead. Confirm you joined the official network, not a similarly named fake one.

Cloud storage

Cloud storage keeps files on a company's servers so you can open them from other devices, such as iCloud, Google Drive or OneDrive. Your files are only as safe as your account, so use a strong unique password and two-factor authentication. Check whether a file is stored only in the cloud, only on the device, or both.

Email attachments

Open attachments only when you expect the file and trust the sender. Check the real email address and the file type; unexpected .exe, .zip or unusual documents can carry malware. If a message looks odd, contact the person through a number or account you already have instead of opening the file.

Digital footprints

A digital footprint is the trail of information you leave online, including posts, photos, comments, accounts and data collected about you. Even deleted posts can be saved or shared by others. Search your name occasionally, tighten privacy settings, and think twice before posting something you would not want a school or employer to see.

Social app privacy

In a social app's privacy settings, choose who can see your posts, story and location, and who can message or tag you. Turn off location sharing when you do not need it, and review tagged photos. A public account can be seen by anyone, including people you do not know.

Blocking a number

Blocking a number stops calls and texts from that number from ringing through on most phones. On iPhone, open the call or thread, tap the info button, and choose Block this Caller. Blocked messages may still be stored in a filtered list, and a person can try a different number, so also report harassment if it continues.

Backing up a phone

A backup is a copy of your apps, photos, settings and data that you can use if the phone is lost, broken or reset. On iPhone you can back up with iCloud or a computer. Back up before a major update or trade-in, and check that recent photos actually appear in the backup or photo library.

App permissions

App permissions are the kinds of access an app asks for, such as the camera, microphone, photos, location or contacts. Grant only what the app needs for a feature you actually use. You can change permissions later in Settings, and you can often choose While Using the App instead of Always for location.

Clearing a browser cache

A browser cache stores pieces of websites so pages can load faster next time. Clearing the cache can fix a page that looks stuck or outdated, but you may need to log in again and pages may load more slowly at first. In Safari on iPhone, you can clear history and website data in Settings.

Pairing a Bluetooth device

To pair headphones or a speaker, put the device in pairing mode, open Bluetooth in Settings, and tap the device's name. Stay close during setup, and type a PIN if asked, often 0000 or 1234 if a manual does not give another code. Forget the device in Settings if it will not reconnect, then pair it again.

If a phone gets wet

If a phone gets wet, take it out of the water, power it off if it is on, and do not charge it or plug anything in. Dry the outside with a cloth and let it dry in a warm, dry place. Skip a bag of rice, which can leave dust and does not dry the inside well. If it was in dirty or salt water, or it will not turn on later, get professional help.

Dark mode

Dark mode uses a darker background that some people find easier on the eyes in low light and that can save a little battery on phones with OLED screens. It does not automatically make every app easier to read. You can schedule it in Settings or switch it in Control Center.

Muting a group chat

Muting a group chat keeps the conversation but stops most notifications, so your phone is not buzzing all day. On iPhone, open the thread, tap the group name or info button, and turn on Hide Alerts. You can still open the chat when you want to catch up.

Washing your hands

Wash your hands with soap and water for about 20 seconds, including the backs, between the fingers and under the nails, then rinse and dry. Do this before eating, after using the bathroom, and after coughing or handling shared surfaces. Use hand sanitizer with at least 60 percent alcohol when soap and water are not available, but wash with soap if hands are visibly dirty.

Getting enough sleep

Most teenagers need about 8 to 10 hours of sleep, and most adults need about 7 or more. A regular bedtime, a darker quieter room, and putting screens away before bed can help. If you often cannot sleep, snore loudly, or feel exhausted every day, talk with a parent, school nurse or doctor.

Drinking enough water

Your body needs water throughout the day, and thirst is a useful signal. A rough guide is pale yellow urine; very dark urine can mean you need more fluids. You usually need more water in heat or during exercise. If a doctor has given you fluid limits, follow that advice instead of general tips.

Stretching

Stretching can help you move more comfortably, especially after a short warm-up when muscles are less cold. Move into a stretch gently, breathe, and hold it without bouncing or pushing into sharp pain. If you have an injury, follow a coach or clinician's advice instead of forcing a stretch.

Sunscreen

Sunscreen helps protect skin from the sun's ultraviolet rays, which can cause sunburn and raise long-term skin cancer risk. Use a broad-spectrum sunscreen of at least SPF 30, apply it before you go out, and reapply after swimming, sweating or a couple of hours outdoors. Sunscreen is one part of sun safety, along with shade, clothing and sunglasses.

Cleaning a small cut

For a small cut, wash your hands, then rinse the wound with clean water and gently clean around it. Use light pressure with a clean cloth if it is bleeding, then add a bandage. Skip harsh cleaners in the wound unless a clinician tells you to use them. Get medical care if bleeding will not stop, the cut is deep or dirty, or you have not had needed tetanus shots.

Treating a minor burn

For a small heat burn, cool the area under cool running water for about 10 to 20 minutes. Do not use ice, butter or toothpaste. You can cover it loosely with a clean bandage after cooling. Get medical care for burns that are large, deep, blistered over a wide area, on the face, hands, feet or joints, or if you are not sure it is minor.

Choking first aid

If someone is choking and cannot cough, speak or breathe, call emergency services right away and ask someone to get help. For a conscious adult or older child, trained first aid uses back blows and abdominal thrusts to try to clear the airway. This is not a substitute for a first-aid class, and the steps differ for infants and for someone who becomes unresponsive.

When to call 911

Call 911 in the United States for a medical, fire or safety emergency that needs help right away, such as trouble breathing, chest pain, a serious injury, a seizure that will not stop, a fire, or a crime in progress. Stay as calm as you can, give the location, and follow the dispatcher's instructions. If you are not sure it is an emergency, it is still reasonable to call.

RICE for a sprain

RICE stands for rest, ice, compression and elevation, a common first step for a mild sprain. Rest the joint, apply a cold pack wrapped in a cloth for short periods, use a wrap if you have been shown how, and keep the area raised. See a doctor or athletic trainer if you cannot bear weight, the joint looks deformed, or pain and swelling are severe or not improving.

Screen eye strain

Long screen time can make eyes feel dry, tired or sore. Try the 20-20-20 idea: about every 20 minutes, look at something about 20 feet away for 20 seconds, blink often, and raise the brightness so you are not squinting. If headaches or vision changes keep happening, get your eyes checked.

Good posture

Good posture means sitting or standing so your ears, shoulders and hips line up reasonably well, with your back supported and both feet on the floor when you sit. Keep screens at about eye level so you are not craning your neck down. Change positions and stand up sometimes; no single pose is meant to be held all day.

Warming up before exercise

A warm-up raises your heart rate gently and moves the muscles you are about to use, such as a few minutes of brisk walking or light versions of the activity. It can make exercise feel easier and may lower injury risk compared with starting at full speed while cold. Save long, deep stretches for after the body is already warm, unless a coach has given you a different plan.

Reading a nutrition label

A Nutrition Facts label shows serving size first, then calories and nutrients in one serving. If you eat two servings, double the numbers. The percent daily value is a rough guide based on a typical 2,000-calorie diet, not a personal target for every person. Use the ingredients list if you need to avoid a specific allergen.

Food allergies

A food allergy is an immune system reaction that can be mild or life-threatening. Common allergens include peanuts, tree nuts, milk, eggs, soy, wheat, fish and sesame, but any food can be a problem for someone. An intolerance is usually uncomfortable but is not the same as an allergy. Take a diagnosed allergy seriously, read labels, and follow a doctor's emergency plan, including epinephrine if it was prescribed.

Caffeine

Caffeine is a stimulant in coffee, tea, many sodas and energy drinks. It can help you feel more alert, but too much can cause jitters, a fast heartbeat or trouble sleeping, especially later in the day. Energy drinks can be very high in caffeine. If caffeine makes you unwell or you have a heart condition, ask a doctor what is safe for you.

Talking about stress

Stress is your body's response to pressure, and it helps to talk with a parent, counselor, coach or another trusted adult instead of keeping it all in. Short-term tools include sleep, movement, taking a break, and slow breathing. If stress or sadness lasts, or you have thoughts of hurting yourself, tell an adult right away or call or text 988 in the United States for the Suicide & Crisis Lifeline.

Brushing and flossing

Brush your teeth twice a day with fluoride toothpaste and clean between your teeth once a day with floss or another interdental cleaner. Brush gently along the gumline rather than scrubbing hard. Regular dental checkups help catch problems early, and a dentist can show you a technique that fits your teeth.

Concussion warning signs

A concussion is a brain injury from a blow or jolt to the head or body. Warning signs include headache, confusion, nausea, dizziness, balance problems, unusual sleepiness, or acting different from usual. Stop playing and see a medical professional. Returning to sports the same day is unsafe, even if you feel better quickly.

Cooling down after exercise

A cool-down is a few minutes of easier movement after a hard workout, such as a slow jog or walk, so your heart rate can come down gradually. It is a good time for gentle stretching while muscles are still warm. Stop and get help if you feel chest pain, faint, or severely short of breath.

Making a budget

A budget is a plan for your money. List your income, then list needed expenses such as food, transportation and bills, then savings, then wants. If spending is higher than income, cut wants first or look for more income. Checking it weekly helps you catch problems early.

Saving money

Saving means setting money aside for later instead of spending all of it now. Paying yourself first, even a small amount from each paycheck or allowance, adds up. Keep savings in a separate account if you can, and pick a goal, such as an emergency fund or a purchase, so the money has a purpose.

Checking and savings accounts

A checking account is meant for everyday spending with a debit card or transfers. A savings account is meant to hold money you do not plan to spend right away and may pay a little interest. Some banks limit certain savings transfers, and both accounts can have fees, so read the account terms.

Interest

Interest is the cost of borrowing money or the money you earn for keeping money in some accounts. If you borrow, you usually pay back the amount plus interest. If a savings account pays interest, the bank pays you a percentage. A higher rate helps you more when you save and costs you more when you borrow.

Debit versus credit cards

A debit card spends money that is already in your checking account. A credit card borrows money you have to pay back, often with interest if you do not pay the full bill on time. A credit card can help build a credit history if used carefully, but carrying a balance can get expensive. Treat both as real money.

Credit scores

A credit score is a number lenders use to estimate how reliably you have repaid borrowed money. Paying bills on time and keeping credit card balances low usually helps. You generally need a credit account in your name, such as a card or loan, before a score is created. Checking your own score does not hurt it.

Pay stubs

A pay stub is the record that comes with a paycheck. It shows gross pay, then deductions such as taxes and benefits, and the net pay you actually receive. Check the hours, pay rate and deductions so you can catch mistakes. Keep stubs for your records, especially at tax time.

Sales tax

Sales tax is a tax added to many purchases, set by the state or local government. The register total can be higher than the shelf price because tax is added at checkout. Rates and which items are taxed vary by place, so the same product can cost a little more in one city than another.

Compound interest

Compound interest is interest earned on both the original amount and the interest already added. In savings, that can help money grow faster over time. On a credit card or loan, it can make a balance grow if you pay only a little and interest keeps being added. Time and the interest rate both matter a lot.

Needs versus wants

Needs are things you must have or that would cause real harm to go without, such as food, housing, medicine and essential transportation. Wants make life nicer but can wait, such as upgrades, snacks or extra subscriptions. When money is tight, cover needs and a little savings first, then decide which wants are worth it.

Emergency funds

An emergency fund is money set aside for unexpected costs, such as a broken phone, a car repair or a lost shift, so you do not have to borrow right away. Start small if needed and keep it in a savings account you can reach without a penalty. Use it for true surprises, then build it back up.

Avoiding money scams

A money scam tries to get you to send cash, gift cards, crypto or account codes, often by pretending to be a company, a crush, a prize or someone in trouble. Pause if someone rushes you or asks you to keep it secret. Do not send money or codes to someone you have not verified, and check a company's real number or website yourself.

Direct deposit

Direct deposit sends your paycheck electronically into your bank account instead of giving you a paper check. Your employer needs your routing number and account number, which are on a check or in your banking app. Check the first deposit to confirm the amount and the account are correct, and tell your employer if you change banks.

Hourly pay versus salary

Hourly pay is a set amount for each hour you work, and overtime rules may apply if you work extra hours. A salary is a fixed amount for a pay period, often quoted as a yearly figure, even if some weeks are longer than others. Compare offers by estimating total pay, benefits and expected hours, not only the headline number.

Writing a resume

A resume is a short summary of your work, school, skills and activities for a job or program. Put your name and contact info at the top, then education, experience and skills, using short bullet points that start with strong verbs and show what you did. Keep it to one page if you are early in your career, and tailor it to the role.

Job interviews

A job interview is a conversation to see if you and the role are a good fit. Read the job post, prepare a few examples of work or school you have done, and be ready to ask one or two questions about the job. Arrive a little early, listen carefully, and send a short thank-you message afterward.

Tipping

Tipping is an extra payment for service, common in U.S. restaurants, hair salons and for delivery. Many people tip about 15 to 20 percent of the pre-tax bill for table service when the service was fine. Check the receipt; some places already add a service charge. Rules differ by country, so look it up when you travel.

Opening a bank account

To open a checking or savings account, a bank or credit union usually asks for photo ID, your Social Security number or ITIN if you have one, and a small opening deposit. Compare fees, overdraft rules and whether you need a parent or guardian as a joint owner if you are under 18. Read the account agreement before you sign.

Gross versus net pay

Gross pay is what you earn before deductions. Net pay, or take-home pay, is what you actually receive after taxes and other deductions such as health insurance. Compare job offers by looking at both the pay rate and what is taken out, not only the headline wage.

Kitchen knife basics

Keep fingers curled under on the hand that holds the food, and cut with a claw grip so fingertips stay back from the blade. Use a stable board, don't try to catch a falling knife, and wash knives carefully by hand or as the maker directs. A sharp knife is easier to control than a dull one.

Boiling versus simmering

Boiling means the liquid is at 212°F (100°C) at sea level, with large, rolling bubbles. Simmering is gentler, with small bubbles that rise slowly, usually just below a boil. Use a boil for pasta or reducing a liquid quickly, and a simmer for soups, sauces and tougher cuts of food that need steady, gentle heat.

Sautéing

Sautéing is cooking food quickly in a little oil or butter over medium-high heat, usually in a wide pan. Heat the pan first, don't crowd the food so it browns instead of steaming, and stir or toss as it cooks. Cut pieces to a similar size so they finish at the same time.

Baking versus roasting

Baking and roasting both use dry oven heat. People usually say baking for breads, cakes and other batters, and roasting for meats and vegetables, often at a higher temperature so the outside browns. Follow the recipe temperature and use the rack position it calls for.

Scrambling eggs

Beat the eggs with a pinch of salt. Warm a little butter or oil in a nonstick pan over medium-low heat, pour in the eggs, and stir gently as they set. Take them off the heat while they still look slightly moist; they keep cooking in the pan.

Boiling eggs

Place eggs in a saucepan and cover them with an inch of cold water. Bring to a boil, then turn off the heat, cover, and let sit: about 6 to 8 minutes for a jammy yolk, or 10 to 12 minutes for a firm hard-boiled yolk. Move the eggs to cold water so they stop cooking and are easier to peel.

Food safety temperatures

Cook poultry to 165°F (74°C) and ground beef to 160°F (71°C). Steaks and chops are often considered safe at 145°F (63°C) with a short rest, and leftovers should be reheated to 165°F. Use a food thermometer in the thickest part, not just color, and keep cold food at or below 40°F (4°C).

Storing leftovers

Cool leftovers and refrigerate them within two hours, or within one hour if the food has been in a hot room. Use shallow containers so they cool faster, eat or freeze them within a few days, and reheat until steaming hot. When in doubt, throw it out rather than risk leftover food that smells or looks off.

Defrosting food safely

The safest ways to thaw food are in the refrigerator, under cold running water, or in the microwave if you will cook it right away. Do not thaw meat or poultry on the counter at room temperature, where the outside can sit in the danger zone while the inside is still frozen. Cook food thawed in the microwave immediately.

Preventing cross-contamination

Cross-contamination is when germs from raw meat, poultry or seafood get onto ready-to-eat food. Use separate cutting boards or wash the board, knife and hands with hot soapy water after cutting raw meat. Keep raw meat on a plate on the bottom fridge shelf so juices cannot drip onto other food.

Best-by and use-by dates

A use-by or expiration date is about safety for some foods, especially infant formula, and you should follow it. A best-by or best-before date is usually about quality, not an automatic deadline; many foods are still fine if they were stored well and show no spoilage. When a food looks, smells or feels wrong, do not eat it even if the date has not passed.

Making oatmeal

For stovetop oats, use about 2 cups of water or milk per 1 cup of rolled oats, a pinch of salt, and simmer, stirring, until thick and creamy, often 5 minutes. Quick oats cook faster; steel-cut oats take longer and need more liquid. Sweeten or add fruit after cooking if you want.

Making pancakes

Mix the dry ingredients, then the wet, and stir just until combined; a few lumps are fine and help keep pancakes tender. Cook on a greased medium pan until bubbles form and the edges look set, then flip once and cook the other side. Keep the heat moderate so the inside cooks before the outside burns.

Making a grilled cheese

Butter the outside of two bread slices, add cheese between them, and cook in a skillet over medium-low heat until the bread is golden and the cheese has melted, flipping once. Covering the pan for a minute can help the cheese melt without burning the bread.

Making a quesadilla

Scatter cheese and any fillings on one half of a tortilla, fold it over, and cook in a lightly oiled skillet over medium heat until both sides are golden and the cheese melts. Let it sit a minute before cutting so the filling doesn't slide out.

Salting pasta water

Salt the water after it is boiling, just before you add the pasta. The pasta absorbs some of that seasoning as it cooks, so the finished dish tastes better than if you only salt the sauce. A common starting point is about 1 tablespoon of kosher salt per 4 quarts of water, then adjust to your taste and any doctor's advice on sodium.

Microwave safety

Use microwave-safe glass or labeled plastic, not metal or foil, which can spark. Watch out for steam when you uncover a hot container, and stir food so it heats evenly. Superheated water can erupt, so use a microwave-safe container and care when heating plain water. If a dish says do not microwave, follow that.

Grease fires

If oil in a pan catches fire, turn off the heat if you can do it safely and slide a metal lid over the pan to smother the flames. Never pour water on a grease fire; it can explode the fire outward. Baking soda can help on a small pan fire. If the fire is spreading, leave, close the door, and call 911.

American football downs

A down is one play. The offense has four downs to gain 10 yards. If they succeed, they get a new set of downs. If they don't, the other team usually takes over. Teams often punt or try a field goal on fourth down instead of risking a turnover on downs.

Touchdowns and field goals

A touchdown is worth 6 points when the ball is carried or caught in the opponent's end zone. The team can then try an extra point kick (1) or a two-point conversion. A field goal is normally 3 points, kicked through the goalposts, often on fourth down or at the end of a half.

Baseball strikes and innings

A strike is a pitch in the strike zone that the batter does not hit fairly, or a swing and a miss, or a foul (except a foul cannot be strike three unless it is a bunt). Three strikes make an out. An inning is a turn for both teams to bat; a regulation game is usually nine innings.

Golf scoring

In stroke play, the person with the fewest total shots wins. Par is the expected number of strokes for a hole. A birdie is one under par, an eagle is two under, and a bogey is one over par. Lower totals are better.

Freestyle swimming

Freestyle usually means the front crawl: alternate arm strokes, a flutter kick, and breathing to the side. Keep your body fairly long and level, and turn your head to breathe rather than lifting it straight up. In a freestyle event you may use any stroke, but crawl is the fastest for most people.

Basketball layups

A layup is a close-range shot off the backboard while moving toward the hoop. Dribble in, pick up the ball, and jump off the opposite foot from the shooting hand: right-hand layup, jump off the left foot. Use the backboard square as a target, and protect the ball with your body.

Chess check and checkmate

Check means your king is under attack and you must get out of it by moving the king, blocking the attack, or capturing the attacking piece. Checkmate means the king is in check and there is no legal way out, so the game is over and that player loses. You cannot make a move that leaves your own king in check.

Castling

Castling is a special king-and-rook move: the king moves two squares toward a rook, and that rook jumps to the square the king crossed. You can castle only if neither piece has moved, the squares between them are empty, and the king is not in check and does not pass through or land on an attacked square.

Sudoku

Sudoku is a puzzle on a 9-by-9 grid divided into 3-by-3 boxes. Fill every row, column and box with the digits 1 through 9, each used once. Start with cells that have the fewest possibilities, pencil in candidates, and never guess if a logical next number is available.

Uno

In Uno, you take turns playing a card that matches the color or number (or symbol) of the card on the pile, or you play a wild. Draw if you cannot play. Action cards can skip, reverse, or make the next player draw. Say “Uno” when you have one card left, or you may have to draw if someone catches you.

In-game purchases

In-game purchases are optional items, currency or passes you buy with real money inside a game. Set a password, use purchase approvals, and check platform spending limits so a game cannot charge you by accident. Treat leftover currency as money already spent, and don't feel you have to buy an advantage to play.

Checking tire pressure

Look up the recommended PSI on the driver's door sticker, not only the tire sidewall, which shows the maximum. Check when the tires are cold, unscrew the valve cap, press a gauge on the valve, and add or release air until you hit the number. Recheck all four tires, and the spare if you have one.

Pumping gas

Park at the pump, turn the car off, and open the fuel door. Choose the grade your owner's manual recommends, usually regular unless the car requires premium. Insert the nozzle fully, pump, then wait a moment, hang the nozzle up, and tighten the cap until it clicks if it is a click cap. Don't smoke or use your phone in a way that distracts you at the pump.

Checking engine oil

Park on level ground, turn the engine off, and wait a few minutes. Pull out the dipstick, wipe it, put it back in fully, then pull it out again and read the level between the min and max marks. If it is low, add the oil type in your owner's manual a little at a time and recheck. A warning light or a very low level means you should not keep driving.

Jump-starting a car

Only jump-start if both batteries are the same voltage, usually 12 volts, and you know the correct terminals. Connect the red clamp to the dead battery's positive terminal, then to the good battery's positive. Connect the black clamp to the good battery's negative, then to an unpainted metal ground on the dead car, not the dead negative terminal if the manual says not to. Start the good car, then the dead one, and remove the cables in reverse order. If you are unsure, call for roadside help.

Changing a spare tire

Pull well off the road, turn on hazard lights, and set the parking brake. Loosen the lug nuts slightly before jacking, jack at the lift point in the owner's manual, remove the nuts, swap the wheel, snug the nuts, lower the car, then tighten the nuts in a star pattern. A donut spare is usually for short, slower trips to a shop, not highway speeds for long distances.

Dashboard warning lights

A red oil, brake or temperature warning usually means you should stop safely as soon as you can and check the manual or get help. An amber check-engine or tire light often means something needs service soon, but not always an instant stop. Look up the exact symbol in your owner's manual instead of ignoring a light.

Seat belts

A seat belt should sit across the hips and mid-chest, not the stomach or neck, and it should be snug. Everyone in the car should buckle up, including the back seat. A belt works with the airbag; sitting too close or leaving the belt off can make a crash much more dangerous.

Car insurance basics

Car insurance helps pay for damage or injury after a crash, theft or other covered events, according to your policy. Liability coverage pays others if you are at fault; collision and comprehensive cover damage to your own car in different situations. State laws set minimums, and a deductible is what you pay first before the insurer pays the rest.

Getting a learner's permit

A learner's permit lets you practice driving with restrictions before a full license. Rules vary by state, but you usually have to be a minimum age, pass a written knowledge test and an eye test, and complete an application with ID and, if you are a minor, a parent or guardian's consent. Drive only with the passengers and hours your state allows.

Parallel parking

Line up with the car in front of the space, about two to three feet away. Reverse and turn toward the curb to enter the space, then straighten and turn the other way to tuck the bumper in. You should end up a reasonable distance from the curb, usually within about 12 inches in many tests, without hitting the cars around you. Practice in an empty lot first.

Pedestrian safety

Cross at a corner or marked crosswalk when you can, look left, right, then left again, and make sure drivers have stopped before you step out. On a two-way street, watch for turning cars. At night, wear something visible, and stay off your phone while crossing. Drivers should yield, but do not assume they have seen you.

Locking a bicycle

Lock the frame and if you can a wheel to a solid rack, using a sturdy U-lock or a quality heavy chain, not only a thin cable. Don't leave the lock near the ground where it is easier to attack, and take lights and loose bags with you. Register the bike and photograph the serial number in case it is stolen.

Tying a necktie

For a common four-in-hand knot, drape the tie around your neck with the wide end hanging lower. Wrap the wide end across the narrow end, around the back, and across the front again, then up through the neck loop and down through the front knot. Slide the knot up and dimple the center if you want a neater look.

Sewing on a button

Thread a needle and knot the end. From the back of the fabric, sew through each pair of buttonholes several times, leaving a tiny shank of thread under the button if the fabric is thick, then wrap the thread around that shank and knot it on the back. Match the thread color and don't pull so tight that the fabric puckers.

Using a fire extinguisher

Use a fire extinguisher only if the fire is small, you have a clear exit, and you know what is burning. Remember PASS: pull the pin, aim at the base of the fire, squeeze the handle, and sweep from side to side. If the fire grows or the room fills with smoke, leave and call 911.

Smoke alarms

Smoke alarms should be on every level of a home, inside bedrooms, and outside sleeping areas. Test them monthly, replace batteries when the unit chirps or as the maker directs, and replace the whole alarm when it reaches the date on the back, often after about 10 years. Never take the battery out just to stop a nuisance chirp without fixing the cause.

Airport security basics

At U.S. airport security, have your ID and boarding pass ready, and follow the bin rules for shoes, laptops and liquids. Liquids in carry-on bags generally must be in containers of 3.4 ounces (100 ml) or less, in one quart-size bag, with exceptions such as medically necessary items you should declare. Put metal items in a bin, and wait for the officer's instructions.
